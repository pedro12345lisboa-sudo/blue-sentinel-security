# Sentinel Agent

A **cross-platform C++20 security agent** designed for high-performance endpoint telemetry collection. Built with modern C++ practices, modular architecture, and zero external runtime dependencies.

## Design Goals

| Goal | Implementation |
|------|----------------|
| **Performance** | Lock-free ring buffers, batch processing, zero-copy where possible |
| **Portability** | Abstract platform layer: Linux (eBPF, auditd), Windows (ETW, WMI), macOS (OpenBSM) |
| **Security** | HMAC-SHA256 message authentication, no plaintext secrets, memory-safe patterns |
| **Observability** | Structured JSON logging (spdlog), Prometheus metrics, health endpoints |
| **Deployability** | Single binary, systemd/Windows service support, Docker-friendly |

## Key Components

### 1. Event Collection (`src/collector/`)

| Platform | Mechanism | Events Captured |
|----------|-----------|-----------------|
| **Linux** | eBPF (kprobe/tracepoint) + auditd | Process exec, file ops, network, syscalls |
| **Windows** | ETW (kernel + user) + WMI | Process create, image load, registry, DNS |
| **macOS** | EndpointSecurity framework | Process, file, network, auth events |

### 2. Normalization (`src/core/normalizer.cpp`)

All events normalized to **common schema** (JSON, ECS-compatible):

```json
{
  "event_id": "uuid-v4",
  "timestamp": "2024-01-15T10:30:45.123Z",
  "agent": { "id": "agent-001", "version": "1.0.0", "hostname": "web-01" },
  "process": { "pid": 1234, "ppid": 1, "name": "powershell.exe", "cmdline": "...", "hashes": {...} },
  "network": { "src_ip": "192.168.1.50", "dst_ip": "10.0.0.1", "dst_port": 443, "protocol": "tcp" },
  "file": { "path": "C:\\temp\\malware.exe", "operation": "create", "hashes": {...} }
}
```

### 3. Detection Engine (`src/detection/`)

- **Sigma rule parser** (subset: selection, condition, timeframe)
- **YARA integration** via `libyara` for file scanning
- **Rule hot-reload** via inotify/ReadDirectoryChangesW
- **Performance**: < 1ms per event for 1000 rules

### 4. Transport (`src/transport/`)

| Protocol | Use Case |
|----------|----------|
| **ZeroMQ PUB/SUB** | High-throughput local collector |
| **HTTPS/REST** | Direct to backend (HMAC auth) |
| **Syslog RFC 5424** | SIEM integration |
| **File/JSONL** | Offline/air-gapped environments |

## Authentication & Security

### HMAC-SHA256 Message Authentication

```cpp
// include/security/hmac.hpp
class HMACAuthenticator {
public:
    // Sign: HMAC-SHA256(timestamp + "." + body, secret)
    std::string sign(const std::string& payload, const std::string& secret);
    
    // Verify: constant-time comparison
    bool verify(const std::string& payload, const std::string& signature, const std::string& secret);
};
```

- **Timestamp** prevents replay attacks (5 min window)
- **Constant-time comparison** prevents timing attacks
- **Key rotation** supported via key ID in header

### Memory Safety

- **No raw pointers** in public APIs
- **`std::span`, `std::vector`, `std::string_view`** for zero-copy
- **RAII** for all resources (file handles, sockets, memory)
- **AddressSanitizer** clean in CI

## Build System (CMake)

```cmake
# CMakeLists.txt
cmake_minimum_required(VERSION 3.20)
project(sentinel-agent VERSION 1.0.0 LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# Dependencies via FetchContent
include(FetchContent)
FetchContent_Declare(spdlog GIT_REPOSITORY https://github.com/gabime/spdlog GIT_TAG v1.12.0)
FetchContent_Declare(nlohmann_json GIT_REPOSITORY https://github.com/nlohmann/json GIT_TAG v3.11.2)
FetchContent_Declare(zeromq GIT_REPOSITORY https://github.com/zeromq/cppzmq GIT_TAG v4.9.0)

# Platform-specific
if(CMAKE_SYSTEM_NAME STREQUAL "Linux")
    find_package(libbpf REQUIRED)
    find_package(libaudit REQUIRED)
elseif(CMAKE_SYSTEM_NAME STREQUAL "Windows")
    find_package(ETW REQUIRED)
endif()
```

## Deployment

### Linux (systemd)

```ini
# /etc/systemd/system/sentinel-agent.service
[Unit]
Description=Sentinel Agent
After=network.target

[Service]
Type=simple
User=sentinel
ExecStart=/usr/local/bin/sentinel-agent --config /etc/sentinel/agent.yaml
Restart=on-failure
RestartSec=5
AmbientCapabilities=CAP_BPF CAP_PERFMON

[Install]
WantedBy=multi-user.target
```

### Windows (NSSM)

```powershell
nssm install SentinelAgent "C:\Program Files\Sentinel\sentinel-agent.exe" "--config C:\ProgramData\Sentinel\agent.yaml"
nssm set SentinelAgent Description "Sentinel Security Agent"
nssm set SentinelAgent AppStdout "C:\ProgramData\Sentinel\logs\stdout.log"
nssm set SentinelAgent AppStderr "C:\ProgramData\Sentinel\logs\stderr.log"
```
