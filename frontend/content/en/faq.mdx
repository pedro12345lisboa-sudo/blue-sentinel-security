## Are the lab events real?

No. They are synthetic events generated for demonstration. There is no real telemetry from any machine and no production data anywhere in the flow. The ethical use notice appears at the entrance of the lab.

## Can I use the lab to test attacks?

No. The content here is strictly defensive and educational. There are no offensive payloads, and nothing should be used against a system you do not own or do not have authorization to test.

## What technologies do you work with?

The repository uses Next.js and TypeScript on the frontend, FastAPI and Python on the backend, PostgreSQL and Redis for data, Docker Compose for orchestration and C++20 in the agent under construction. The full list is on [Technical skills](/about).

## How are the projects documented?

Every case study follows the same format: Problem, Context, Solution, Architecture, Technical decisions and why, Challenges, Results, Lessons and Links. Unmeasured results stay as `[MEASURED METRIC]`.

## I found a vulnerability. What should I do?

Use the [Security](/security) page or write to `security@blue-sentinel.local`. Responsible disclosure, with a stated response window. There is no bug bounty program: this is a personal portfolio.

## Can I contribute?

Yes. Open an issue in the repository with your proposal; if it changes a rule or a detection, include the sample log you used to validate it.
