dataSource: "Identity provider login signals (Entra ID, Google Workspace) and VPN/RDP logs"
query: |
  SELECT
    user,
    country,
    src_ip,
    ts,
    outcome
  FROM login_events
  WHERE outcome = 'success'
    AND country NOT IN (
      SELECT DISTINCT country
      FROM login_events
      WHERE user = login_events.user
        AND ts < login_events.ts - INTERVAL '90 days'
        AND outcome = 'success'
    )
    AND ts >= now() - INTERVAL '7 days'
  ORDER BY ts DESC;

Valid accounts are the quietest vector because nothing breaks: the login simply succeeds. What is left for the hunt is context — geography, device, time of day and the first action after authentication.

<Callout type="info" title="Read-only log access">The query aggregates login events that have already been collected. No step involves authenticating, testing factors or accessing accounts.</Callout>

## How to use

Run it daily per identity provider, discard travel confirmed with the account holder and hand the remaining cases to the credential attack playbook with the timeline of the first access.
