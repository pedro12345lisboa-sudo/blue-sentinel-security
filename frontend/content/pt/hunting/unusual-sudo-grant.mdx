dataSource: "auth.log e syslog de servidores Linux (eventos sudo e usermod), com histórico de execução por conta"
query: |
  SELECT
    usuario,
    comando,
    host,
    COUNT(*)      AS execucoes,
    MIN(ts)       AS primeira_vez
  FROM sudo_events
  WHERE ts >= agora() - INTERVALO '7 dias'
  GROUP BY usuario, comando, host
  HAVING usuario NOT IN (
      SELECT usuario
      FROM sudo_events
      WHERE ts < agora() - INTERVALO '30 dias'
  )
  ORDER BY primeira_vez DESC;

A diferença entre rotina e ameaça aqui é histórico, não o comando em si: o mesmo `sudo` é banal para o administrador e revelador para a conta que nunca o usou.

<Callout type="info" title="Só leitura de logs">A consulta agrega eventos já gravados. Nenhuma etapa envolve executar sudo ou modificar qualquer servidor.</Callout>

## Como usar

Execute semanalmente por servidor, compare com o calendário de manutenção e devolva as primeiras ocorrências sem pedido correspondente ao playbook de conta privilegiada.
