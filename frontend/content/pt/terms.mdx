## Aceitação

Ao navegar neste portfólio você concorda com estes termos. Se não concordar, basta não usar o site — não há cadastro, conta ou serviço contratado.

## Uso permitido

Este é um portfólio **estritamente defensivo e educacional**. Você pode:

- ler artigos, playbooks e write-ups;
- usar o [laboratório](/lab) com eventos **sintéticos**, gerados para demonstração de detecção;
- citar conteúdos com atribuição e link para a fonte.

## Uso proibido

- Utilizar qualquer conteúdo daqui para atacar, testar ou explorar sistemas sem autorização **explícita e documentada** do responsável.
- Tratar eventos do laboratório como telemetria real de produção — são fabricados, sem qualquer máquina ou vítima real.
- Reproduzir identificadores, IPs ou credenciais deste repositório como se fossem dados de produção (tudo é placeholder ou sintético).
