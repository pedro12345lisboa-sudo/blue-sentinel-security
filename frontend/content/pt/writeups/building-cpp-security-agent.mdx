# Construindo um Agente de Segurança em C++20: Arquitetura e Lições Aprendidas

Escrever um agente de segurança em C++ é um rito de passagem para engenheiros de Blue Team que querem entender o que acontece por baixo dos panos. Aqui estão a arquitetura, as decisões e as lições aprendidas da construção do **Sentinel Agent**.

## Por que C++ para um agente de segurança?

| Requisito | Vantagem do C++ |
|-------------|---------------|
| **Desempenho** | Abstrações de custo zero, estruturas lock-free, controle de memória |
| **APIs de plataforma** | Acesso direto a eBPF, ETW, Windows Kernel, macOS EndpointSecurity |
| **Implantação** | Binário estático único, sem runtime, funciona em sistemas air-gapped |
| **Ecossistema** | `libbpf`, `libyara`, `spdlog`, `nlohmann/json`, `cppzmq` |
| **Base de talentos** | Programadores de sistemas entendem memória, concorrência e internas do SO |

### Linux: eBPF + auditd

```cpp
// src/collector/linux/ebpf_collector.cpp
class EbpfCollector : public IEventCollector {
    struct bpf_object* obj_ = nullptr;
    std::vector<bpf_program*> programs_;
    std::unique_ptr<RingBuffer> ring_buffer_;
    
    Result<void> initialize(const CollectorConfig& config) override {
        // Load eBPF object file (compiled from BPF C)
        obj_ = bpf_object__open_file("collector.bpf.o", nullptr);
        if (!obj_) return Err("Failed to open BPF object");
        
        // Attach programs
        for (auto* prog : programs_) {
            auto link = bpf_program__attach(prog);
            if (!link) return Err("Failed to attach BPF program");
        }
        
        // Setup ring buffer for events
        ring_buffer_ = std::make_unique<RingBuffer>(config.ring_buffer_size);
        return Ok();
    }
    
    EventBatch collect_batch(size_t max_events, std::chrono::milliseconds timeout) override {
        EventBatch batch;
        batch.reserve(max_events);
        
        // Poll ring buffer with timeout
        while (batch.size() < max_events) {
            void* data = ring_buffer_->poll(timeout);
            if (!data) break;
            
            auto event = parse_bpf_event(static_cast<bpf_event*>(data));
            if (event) batch.push_back(std::move(event));
        }
        return batch;
    }
};
```

```c
SEC("tracepoint/sched/sched_process_exec")
int trace_exec(struct trace_event_raw_sched_process_exec* ctx) {
    bpf_event event = {};
    event.type = EVENT_PROCESS_EXEC;
    event.timestamp = bpf_ktime_get_ns();
    event.pid = bpf_get_current_pid_tgid() >> 32;
    event.ppid = ctx->pid;
    
    // Copy comm (process name)
    bpf_probe_read_str(event.comm, sizeof(event.comm), ctx->comm);
    
    // Copy filename (executable path)
    bpf_probe_read_str(event.filename, sizeof(event.filename), ctx->filename);
    
    // Submit to ring buffer
    bpf_ringbuf_output(&events, &event, sizeof(event), 0);
    return 0;
}
```

### Windows: ETW

```cpp
// src/collector/windows/etw_collector.cpp
class EtwCollector : public IEventCollector {
    TRACEHANDLE session_handle_ = 0;
    EVENT_TRACE_PROPERTIES* properties_ = nullptr;
    std::thread consumer_thread_;
    std::atomic<bool> running_{false};
    LockFreeQueue<Event> event_queue_;
    
    Result<void> initialize(const CollectorConfig& config) override {
        // Configure ETW session
        EVENT_TRACE_PROPERTIES props = {};
        props.Wnode.BufferSize = sizeof(props);
        props.Wnode.Flags = WNODE_FLAG_TRACED_GUID;
        props.LogFileMode = EVENT_TRACE_REAL_TIME_MODE;
        props.EnableFlags = EVENT_TRACE_FLAG_PROCESS | EVENT_TRACE_FLAG_IMAGE_LOAD | 
                           EVENT_TRACE_FLAG_NETWORK_TCPIP | EVENT_TRACE_FLAG_REGISTRY;
        
        // Start trace session
        ULONG status = StartTrace(&session_handle_, L"SentinelAgent", &props);
        if (status != ERROR_SUCCESS) return Err("StartTrace failed: " + std::to_string(status));
        
        // Enable providers
        EnableTraceEx2(session_handle_, &MicrosoftWindowsKernelProcess, 
                      EVENT_CONTROL_CODE_ENABLE_PROVIDER, TRACE_LEVEL_INFORMATION, 0, 0, 0, nullptr);
        
        return Ok();
    }
    
    void event_callback(PEVENT_RECORD record) {
        if (!running_) return;
        
        auto event = parse_etw_record(record);
        if (event) {
            event_queue_.push(std::move(event));
        }
    }
};
```

## Normalização: JSON compatível com ECS

Todos os eventos são normalizados para um subconjunto do **Elastic Common Schema (ECS)**:

```cpp
// src/core/normalizer.cpp
struct NormalizedEvent {
    // ECS base fields
    std::string event_id;           // UUID v4
    std::chrono::system_clock::time_point timestamp;
    AgentInfo agent;                // agent.id, agent.version, host.name
    
    // Event categorization
    std::string event_category;     // process, file, network, registry, dns, auth
    std::string event_type;         // start, end, creation, deletion, connection
    std::string event_action;       // exec, write, connect, bind, query
    
    // Process (if applicable)
    std::optional<ProcessInfo> process;
    
    // Network (if applicable)
    std::optional<NetworkInfo> network;
    
    // File (if applicable)
    std::optional<FileInfo> file;
    
    // Registry (if applicable)
    std::optional<RegistryInfo> registry;
    
    // Serialization
    nlohmann::json to_json() const;
};

nlohmann::json NormalizedEvent::to_json() const {
    nlohmann::json j;
    j["@timestamp"] = to_iso8601(timestamp);
    j["event"]["id"] = event_id;
    j["event"]["category"] = event_category;
    j["event"]["type"] = event_type;
    j["event"]["action"] = event_action;
    j["agent"] = agent.to_json();
    
    if (process) j["process"] = process->to_json();
    if (network) j["network"] = network->to_json();
    if (file) j["file"] = file->to_json();
    if (registry) j["registry"] = registry->to_json();
    
    return j;
}
```

## Motor de detecção: Sigma + YARA

### Analisador de Sigma rules (subconjunto)

```cpp
// src/detection/sigma_engine.cpp
class SigmaEngine {
    struct CompiledRule {
        std::string id;
        std::string title;
        std::vector<std::string> mitre_tags;
        std::unique_ptr<ConditionAST> condition;
        Severity severity;
    };
    
    std::vector<CompiledRule> rules_;
    
    Result<void> load_rules(const std::filesystem::path& rules_dir) {
        for (auto& entry : std::filesystem::recursive_directory_iterator(rules_dir)) {
            if (entry.path().extension() == ".yml" || entry.path().extension() == ".yaml") {
                auto rule = parse_sigma_rule(entry.path());
                if (rule) rules_.push_back(std::move(*rule));
            }
        }
        return Ok();
    }
    
    std::vector<Alert> evaluate(const NormalizedEvent& event) {
        std::vector<Alert> alerts;
        for (const auto& rule : rules_) {
            if (rule.condition->evaluate(event)) {
                alerts.push_back(Alert{
                    .rule_id = rule.id,
                    .rule_title = rule.title,
                    .severity = rule.severity,
                    .mitre_tags = rule.mitre_tags,
                    .event = event.to_json()
                });
            }
        }
        return alerts;
    }
};
```

**AST de condição (Abstract Syntax Tree):**

```cpp
// Field comparison with modifiers
class FieldCondition : public Condition {
    std::string field;           // "process.command_line"
    Operator op;                 // EQUALS, CONTAINS, REGEX, CIDR, ENDSWITH
    std::string value;
    Modifier modifier;           // NONE, CASE_INSENSITIVE, ALL, ANY
    
    bool evaluate(const NormalizedEvent& event) const override {
        auto field_value = extract_field(event, field);
        return compare(field_value, value, op, modifier);
    }
};

// Logical operators
class AndCondition : public Condition {
    std::vector<std::unique_ptr<Condition>> children_;
    bool evaluate(const NormalizedEvent& event) const override {
        return std::all_of(children_.begin(), children_.end(),
            [&](auto& c) { return c->evaluate(event); });
    }
};

class NotCondition : public Condition { /* ... */ };
```

### Integração com YARA

```cpp
// src/detection/yara_scanner.cpp
class YaraScanner {
    YR_RULES* rules_ = nullptr;
    YR_COMPILER* compiler_ = nullptr;
    
    Result<void> load_rules(const std::filesystem::path& rules_dir) {
        yr_compiler_create(&compiler_);
        
        for (auto& entry : std::filesystem::recursive_directory_iterator(rules_dir)) {
            if (entry.path().extension() == ".yar" || entry.path().extension() == ".yara") {
                yr_compiler_add_file(compiler_, entry.path().c_str(), nullptr, entry.path().c_str());
            }
        }
        
        yr_compiler_get_rules(compiler_, &rules_);
        return Ok();
    }
    
    std::vector<YaraMatch> scan_file(const std::filesystem::path& file) {
        std::vector<YaraMatch> matches;
        YR_CALLBACK_FUNC callback = [](int msg, void* msg_data, void* user_data) {
            auto& matches = *static_cast<std::vector<YaraMatch>*>(user_data);
            if (msg == CALLBACK_MSG_RULE_MATCHING) {
                YR_RULE* rule = static_cast<YR_RULE*>(msg_data);
                matches.push_back({rule->identifier, rule->tags, rule->metadata});
            }
            return CALLBACK_CONTINUE;
        };
        
        yr_rules_scan_file(rules_, file.c_str(), 0, callback, &matches, 0);
        return matches;
    }
    
    std::vector<YaraMatch> scan_memory(const void* data, size_t size) {
        // Similar, using yr_rules_scan_mem
    }
};
```

## Transporte: HTTPS autenticado por HMAC

```cpp
// src/transport/https_transport.cpp
class HttpsTransport : public ITransport {
    std::string endpoint_;
    std::string hmac_key_id_;
    std::string hmac_secret_;
    cpr::Session session_;
    
    Result<void> send(const EventBatch& batch) override {
        // Prepare payload
        nlohmann::json payload;
        payload["events"] = nlohmann::json::array();
        for (const auto& event : batch) {
            payload["events"].push_back(event.to_json());
        }
        payload["timestamp"] = to_iso8601(std::chrono::system_clock::now());
        payload["agent_id"] = agent_id_;
        
        std::string body = payload.dump();
        
        // Generate HMAC signature
        std::string timestamp = std::to_string(
            std::chrono::duration_cast<std::chrono::seconds>(
                std::chrono::system_clock::now().time_since_epoch()
            ).count()
        );
        
        std::string signing_input = timestamp + "." + body;
        std::string signature = hmac_sha256(signing_input, hmac_secret_);
        
        // Send with headers
        cpr::Response response = session_.Post(
            cpr::Url{endpoint_},
            cpr::Body{body},
            cpr::Header{
                {"Content-Type", "application/json"},
                {"X-Agent-ID", agent_id_},
                {"X-Timestamp", timestamp},
                {"X-Signature", signature},
                {"X-Key-ID", hmac_key_id_}
            },
            cpr::Timeout{30000}
        );
        
        if (response.status_code >= 400) {
            return Err("HTTP " + std::to_string(response.status_code) + ": " + response.text);
        }
        return Ok();
    }
};
```

## Lições aprendidas

### 1. **Abstração de plataforma é difícil, mas vale a pena**

| Abordagem | Veredito |
|----------|---------|
| `#ifdef` em todo lugar | ❌ Insustentável |
| Classe abstrata + factory | ✅ Limpa, testável |
| Binários separados por SO | ❌ Pesadelo de implantação |

### 2. **eBPF é poderoso, mas frágil**

- **CO-RE (Compile Once, Run Everywhere)** é essencial para independência de versão do kernel
- Sempre teste nas versões de kernel alvo
- `bpftool` é seu melhor amigo para depuração

### 3. **ETW é verboso — filtre cedo**

```cpp
// Enable only what you need
props.EnableFlags = EVENT_TRACE_FLAG_PROCESS | 
                    EVENT_TRACE_FLAG_IMAGE_LOAD | 
                    EVENT_TRACE_FLAG_NETWORK_TCPIP;
```

### 4. **Log estruturado desde o primeiro dia**

```cpp
// Use spdlog with JSON formatter
auto logger = spdlog::json_logger_mt("agent");
logger->info("Event collected", 
    {"event_type", "process_exec"},
    {"pid", event.pid},
    {"duration_ms", elapsed.count()});
```
