# Blue Sentinel - Estrutura do Projeto

Comece só com `frontend/`, `backend/` e `docs/`. Crie o resto quando precisar.

- `rules/` guarda apenas dados (YARA, Sigma, patterns), sem código.
- `assets-src/` guarda fontes pesadas (Blender/Figma). Use Git LFS ou deixe fora do repo.
- Só os `.glb` finais vão em `frontend/public/models/`.
- Cache, workers e monitoring ficam dentro de `backend/app/`.
